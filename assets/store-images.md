# Store image sources

Updated October 28, 2026. The three store screenshots are 1280×800 PNGs with no transparency. They are promotional
compositions based on real captures, not new checks of the example books. Originals are preserved. The extension build
copies only icons, so these files are not shipped in the extension package.

Each composition was fitted inside 1280×800 on the same sage background so the headline and the full panel stay in
frame. Panel wording matches the extension: Kindle+ not checked, Available on Kindle+, and Kindle+ was not detected.
